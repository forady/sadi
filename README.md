# For Baby

A personal comfort letter for Nerissa, ready for GitHub Pages.

## Put it on GitHub Pages

1. Create a new public GitHub repository (for example, `for-baby`).
2. Upload everything **inside the `dist` folder** to the repository root: `index.html` and the `assets` folder.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select **main**, choose **/(root)**, and save.

GitHub will show the live link after a minute or two. It normally looks like:

`https://YOUR-USERNAME.github.io/for-baby/`

The music starts only after the first tap because mobile browsers do not allow sound to autoplay before interaction. The song is stored locally in `assets/walong-bilyon.mp3`, so it plays without YouTube ads.
